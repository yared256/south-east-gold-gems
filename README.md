# South East Gold & Gems
`npm install && npm run dev` · `npm run build`
- Company/contact/CEO/licenses/WhatsApp: `src/data/company.js` (set `logo`, `email`, `website` when available)
- Products & gallery: `src/data/products.js` (set `image` paths; add a product = add one object)
- Placeholders are gradient blocks; no remote images are used.
